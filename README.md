# 🎮 Reichlich — Discord Community Landing Page

A landing page for the **Reichlich** Discord community — introducing the server, its team, and the games we play, with a simple form to apply and join.

![Status](https://img.shields.io/badge/status-unfinished-yellow) ![Made in](https://img.shields.io/badge/made%20in-2024-blue)

## Built With

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- Vanilla JavaScript
- [GSAP](https://gsap.com/) + ScrollTrigger + ScrollToPlugin (animations)
- [Font Awesome](https://fontawesome.com/) (icons)
- Google Fonts — Orbitron & Montserrat
- Netlify Forms (application form backend)

## Features

- 🌐 RU / EN language switcher
- 🎥 Animated hero section with a looping video background
- ✨ Scroll-triggered animations (GSAP)
- 👥 Team and games showcase
- 📋 Application form to join the Discord server

## Run Locally

No build step required — just open `index.html` in your browser.

## Status

⚠️ This project is **unfinished**. It was built back in **2024** as a personal/hobby project and is no longer actively maintained. Expect rough edges.
